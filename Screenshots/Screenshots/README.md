# 🎮 Magical Alphabets AR App

An educational **Augmented Reality (AR)** application built with **Unity** and **Vuforia** to help children learn English alphabets through interactive 3D models, quizzes, matching games, and spelling activities.

---

## 📌 Features

- 🔤 Interactive 3D Alphabet Models
- 📱 Augmented Reality using Vuforia
- 🎯 Alphabet Matching Game
- ✍️ Spelling Game
- ❓ Quiz Game
- 👶 Child-Friendly UI
- 🎨 Colorful Learning Experience

---

## 🛠 Technologies Used

- Unity 6
- C#
- Vuforia Engine
- Blender
- Adobe Photoshop
- Canva

## 🚀 How to Run

1. Clone this repository.
2. Open the project in Unity.
3. Install the required Vuforia package.
4. Build and run on an Android device.

## 🎯 Project Purpose

The main goal of this project is to make alphabet learning more engaging and interactive for children using Augmented Reality technology.
